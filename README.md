AI-Powered Retail Credit Risk Assessment & Loan Approval Prediction System

Python | Scikit-learn | Pandas | NumPy | Streamlit | Machine Learning Deployment

Developed an end-to-end machine learning credit risk assessment system to predict loan approval decisions using applicant financial, demographic, and credit history attributes.
Performed data preprocessing including missing value handling, categorical encoding, numerical feature scaling, and exploratory data analysis to prepare loan application data for modelling.
Built and compared classification models including Support Vector Machine (SVC) and Random Forest, applying 5-fold cross-validation and RandomizedSearchCV for hyperparameter optimization.
Achieved 84% validation accuracy with optimized models and evaluated performance using Accuracy, Precision, Recall, F1-score, and Confusion Matrix.
Engineered a real-time prediction application using Streamlit, enabling users to input applicant details and receive instant loan approval predictions.
Integrated trained ML artifacts (loan_status_predictor.pkl and scaler.pkl) into the deployment workflow for consistent preprocessing and model inference.
Created a production-style ML workflow including model training scripts, serialized model files, dependency management, and deployment-ready application structure.
